La façon dont le contenu est stocké, versionné et retrouvé.

Le parti pris fondateur : Git est la base de données. Un dépôt par projet, des
fichiers Markdown à frontmatter YAML, et l'historique, l'attribution et la
relecture fournis par la plateforme.

Couvre aussi le stockage des pièces jointes, qui vivent hors de Git tout en
restant cohérentes avec lui.
